# Storybook

## Introduce

<https://storybook.js.org/docs/get-started/install>

```sh
npx storybook@latest init
```

## Commands

### Upgrade

```sh
npx sb@latest upgrade
```

### Automigrate

```sh
npx sb@latest automigrate
```
