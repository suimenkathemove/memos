# ヘッドレスUIライブラリ

## ヘッドレスUIとは

見た目（スタイル）を持たず、**振る舞いとアクセシビリティだけ**を提供する UI ライブラリ。
Chakra UI や MUI のようなスタイル込みのコンポーネントライブラリと対比される。

提供されるのは主に次のもの。

- キーボード操作（Tab / 矢印キー / Esc / Home・End など）
- フォーカス管理（フォーカストラップ、閉じたときに開いた要素へ戻す）
- WAI-ARIA 属性（`role`、`aria-expanded`、`aria-controls` など）の付与
- 開閉やアクティブ項目といった状態管理

スタイルは利用側が当てるため、デザインシステムに合わせた見た目を作りつつ、
自前実装だと漏れやすいアクセシビリティ対応をライブラリに任せられる。
