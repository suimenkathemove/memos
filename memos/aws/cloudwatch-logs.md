# CloudWatch Logs

## Overview

ログの階層は ロググループ > ログストリーム > ログイベント。

- ロググループ: 保持期間・暗号化・アクセス制御などの設定単位。
- ログストリーム: 同一ソース（コンテナ、Lambdaの実行環境など）のログの並び。
- ログイベント: 1行のログ（タイムスタンプ + メッセージ）。

## 保持期間

デフォルトは「失効しない（Never expire）」なので、指定しないとログが永久に溜まって課金され続ける。
必ず `retention_in_days` を設定する。

指定できる値は決まっている: 1, 3, 5, 7, 14, 30, 60, 90, 120, 150, 180, 365, 400, 545, 731, 1096, 1827, 2192, 2557, 2922, 3288, 3653。

## 自動作成に注意

Lambda や ECS はロググループが無ければ自動作成する（保持期間は無期限）。
そのため IaC で先にロググループを作っておくのが望ましい。
既に自動作成されている状態で Terraform 管理下に置くと `ResourceAlreadyExistsException` になるので `import` する。

## MEMO

- ログを書き込むには、実行ロールに `logs:CreateLogStream` と `logs:PutLogEvents` が必要。
- ロググループを自動作成させる場合は `logs:CreateLogGroup` が必要。
- 課金は 取り込み量 + 保存量 + 検索(Logs Insights)。コストの大半は取り込み量なので、まず出力するログ自体を減らす。
- ロググループを削除するとログイベントも復元できない。長期保管したい場合は S3 へエクスポートするか、Subscription Filter で流す。
